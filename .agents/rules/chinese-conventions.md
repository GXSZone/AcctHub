# AcctHub 中文工程规范

本项目中的所有文档、代码注释与 Git 提交信息均严格使用**简体中文**编写：

1. **项目文档**：
   - 所有新增与更新的 Markdown 文档（含 README、API 文档、架构方案、迁移说明、变更日志等）一律使用简体中文撰写。
   - 仅在涉及专有技术名词、协议名、路径、环境变量、代码标识符或命令行指令时保留原文。

2. **代码注释**：
   - 所有新增或修改的源码（TypeScript / TSX / SQL / CSS / 配置文件）中的单行注释、块注释与 JSDoc/TSDoc 注释一律使用简体中文。
   - 注释聚焦业务意图、边界条件与架构约束，不写无意义的直译注释。
   - 代码标识符（变量名、函数名、类型名、数据库列名、路由路径、环境变量名）仍遵循英文命名规范。

3. **Git 提交信息**：
   - 所有 `git commit` 的标题与正文说明一律使用简体中文。
   - 推荐保留 Conventional Commits 前缀类型并配合中文描述，例如：
     - `feat: 新增代理分站整页实时预览功能`
     - `fix: 修复后台侧栏切换菜单时的跳动问题`
     - `refactor: 统一订单履约引擎与共享领域契约`
     - `docs: 补充多级代理与上游对接中文接口文档`
     - `chore: 新增项目级中文工程规范规则`
