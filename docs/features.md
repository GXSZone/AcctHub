# AcctHub 功能全景介绍

AcctHub 是一款面向边缘计算架构设计的多级代理自动发卡与数字商品交易系统。以下按业务领域介绍系统已经完整实现的各项核心功能。

---

## 1. C 端商城前台与购物体验

- **分栏目录与极速检索**：支持一级分组、二级分类树、置顶精选（`featured`）、全量商品（`all`）及标签筛选，支持关键词检索（匹配多语种标题、副标题、标签与 Slug）及列表/卡片视图切换。
- **实时多币种展示换算**：内置实时参考汇率缓存（CNY / USD / HKD / JPY / KRW），顶部可一键切换展示币种并随商品列表、详情与规格联动换算（实际结算统一以人民币或所选网关实时汇率为准）。
- **智能选品对话（Concierge）**：提供基于关键词语义与大模型接入（可选配置）的自然语言选品接口 `POST /api/storefront/concierge/match`，根据买家需求推荐匹配规格。
- **富文本与安全渲染**：商品详情、公告与帮助中心支持 Markdown / 富文本排版及 `DOMPurify` 前端净洗；支持公告弹窗与置顶播报。
- **离线 2FA 验证码工具**：内置纯浏览器端 TOTP 动态口令计算工具，买家拿到带 `2FA Secret` 的账号凭证后无需离开页面即可本地解析 6 位实时验证码。
- **缺货订阅与到货邮件提醒**：商品售罄时买家可留存邮箱订阅补货通知；后台或上游同步入库时自动向队列推送到货提醒邮件。

## 2. 多形态高转化营销与发卡引擎

系统原生支持多种商品售卖形态与履约模式，通过统一商品编辑器管理，无需插件拼装：

- **标准卡密自动发卡（`cards`）**：支持单商品多规格（Spec）、批导入去重、原子抢占发卡（CAS 乐观锁，绝不超卖或重复发放）。
- **前台预选靓号下单（Card Selection）**：后台可为卡密设置公开标签（`public_label`）与选号加价费用，前台支持按标签挑选具体凭证（仅展示脱敏标签，下单前绝不泄露卡密原文），并以数据库条件锁防止多人争抢同一条卡密。
- **隐藏商品与口令专属访问**：商品可设置为“仅通过直达链接访问”并配置访问口令（`access_password`），适合大客户内部通道或私域限量活动。
- **限时秒杀（Flash Sale）**：支持设置秒杀价、起止时间窗、活动限量池与单笔限购件数，售罄或超时自动恢复常规价格。
- **组合套餐 / 捆绑包（Bundle）**：一个套餐可绑定多个子商品与指定规格；单次下单原子依次从全部子商品扣库并合并发卡，任一子商品缺货立即全量回滚。
- **拼团合租（Group Buy）**：支持配置成团人数（如 2 人/3 人车位）、团购特惠价与拼团有效期；买家可一键开团或加入已有待成团订单，满员后一次性全团并发发卡，超时由 Cron 巡检自动退还余额。
- **游客价 vs 会员专享价分层定价**：商品可分别设定基础零售价与登录会员价，引导游客注册转化。
- **卡密与拼车座位模式**：除通用多行卡密外，也支持按固定席位管理的合租座位库存与到期提醒邮件。
- **分站自营私有商品**：代理分站可上架仅归属于自己店铺的自有卡密商品，强制通过该分站自有收款账户直收，与主站资金及库存完全隔离。

## 3. 多级白牌代理体系与 B2B Open API

- **最多 3 级代理拓扑（L1 / L2 / L3）**：支持分级代理等级（代理开通/升级费、拿货折扣、分站直推返佣、下级育成奖）。
- **独立品牌分站与自定义域名**：
  - 每个认证代理拥有专属二级子域与路径标识（`/s/<slug>` 或 `<slug>.domain`）；
  - 支持接入代理自有顶级域名（结合 Cloudflare for SaaS / Host 解析），实现全站独立 Brand Logo、主题色、页脚与独立 SEO Meta。
- **灵活定价与亏本保护**：代理可独立调整零售加价率，也可以在分站控制台单独对主站商品设定自定义售价；后端实时对比代理拿货底价，防止改价击穿成本或造成倒挂。
- **分站自有收款与严格防二清隔离**：主站管理员可为指定代理开启“允许分站自有收款”；售卖分站私有商品时强制经由该分站自己配置的支付网关直收，禁止进入主站资金池或使用主站余额。
- **B2B 批发 Open API**：代理可随时在后台签发与轮换 `ah_agent_*` 密钥，对接第三方系统完成实时拉取价目表、库存与幂等批采下单（`POST /api/v1/reseller/order`），兼容主流发卡协议格式（`/api/v1/reseller/compat/*`）。
- **推广归因（Affiliate）**：通过 `?ref=<code>` 自动绑定新客推荐关系，订单交付后按配置比例发放可抵扣消费金，发生退款时自动执行追缴冲正。

## 4. 全渠道支付聚合与补偿机制

- **内置支付通道**：
  - **站内余额支付**：登录会员支持使用余额或优惠券/推广消费金组合抵扣，支持充值 CDK 兑换与消费账本追踪；
  - **易支付（Epay）**：完整 MD5 验签表单跳转与异步回调核销；
  - **支付宝当面付（Alipay F2F）**：内置 WebCrypto RSA2 PKCS#8 签名与支付宝公钥验签，生成二维码预下单并支持同步/异步核销；
  - **Stripe Checkout**：完整支持 HMAC-SHA256 `Stripe-Signature` 与 5 分钟时间戳窗口校验，并支持通过原路 API 自动退款与状态轮询；
  - **USDT 多链收单（TRC20 / ERC20 / BEP20）**：通过 4 位小数唯一金额尾数隔离并发撞单，支持实时汇率缓存熔断与链上浏览器自动核单（含 15 秒查询防抖）。
- **先建单后锁库与异步补偿**：
  - 在线异步支付先生成 `pending_payment` 订单与 `payment_intents`，不提前死锁库存；
  - 支付回调验签成功后原子抢占卡密并履约；若极端并发售罄，系统自动将实付金额全额赔付退回会员钱包余额（游客单转入待人工退赔工单），并生成账本记录；
  - 已支付但偶发超时未履约的支付单可通过租约机制与 Cron 补偿任务安全重试，不重复发卡。
- **开发沙盒隔离**：本地开发与沙盒测试提供可控的模拟收银台与演示余额充值；在 `staging` / `production` 环境下全部沙盒路径均不注册（返回 `404`），历史模拟流水与标识在正式核销链路中强制拦截。

## 5. 多上游货源聚合与主备容灾

- **多协议货源接入**：支持标准 `generic_json` 契约、主站互联协议与常见第三方发卡（`acgfaka`、`dujiaoka_like` 等）货源对接；请求报文与响应路径均可在后台抽屉可视化配置并测试连通性。
- **主备多源 Failover 履约**：一个规格可绑定多个上游货源并设置优先级与库存汇总策略（`local_first` / `upstream_only`）；主源欠费或返回明确未受理信号时，系统按规则保护不重复下单，同时可手动或定时追踪在途上游订单结果。
- **上游成本防倒挂保护**：结合货源实时缓存余额与采购单价计算可售库存，防止上游账户余额不足导致前台超卖。
- **人工补发与批量导出安全**：后台支持查看本地与上游在途订单状态并执行人工补发，补发内容自动加密保存；审计日志与 CSV 导出对卡密及敏感字段严格脱敏，并附加防 Excel 公式注入保护。

## 6. 社交登录、邮件引擎与扩展 Webhook

- **多平台 OAuth 社交登录**：支持 QQ、微信、Google、GitHub OAuth 登录绑定，并支持分站独立白牌回调与状态校验。
- **站点级邮件投递与 Outbox 队列**：支持 Resend、Mailgun、SendGrid 与自定义 HTTP Webhook 发信；主站与认证分站可独立配置发件身份、自定义订单凭证邮件模板；所有订单发信、补发与到货通知统一进入 `mail_outbox` 可重试队列，由 Worker 定时异步投递。
- **业务出站 Webhook**：支持向管理员配置的外部 ERP / CRM / 通知地址推送 `order.created`、`order.delivered`、`order.refunded` 事件，附带 `X-AcctHub-Event`、`X-AcctHub-Timestamp` 与 HMAC-SHA256 签名，可选允许认证接收方通过回填接口驱动外部履约结果写入。

---

## 7. 安全风控、凭证加密与财务守恒

- **5 维纵深风控与紧急止损**：涵盖 0 元购/成本击穿防线、5 分钟/1 小时全局出卡速率限制、上游日采购额度上限、大额订单人工待审以及 IP/CIDR 黑名单；触发告警或切换紧急模式（正常 / 暂停发卡 / 紧急维护闭店）时自动向管理员连发紧急邮件。
- **管理员 TOTP 2FA 与操作审计**：主站管理员可绑定 2FA，高危后台操作（导出、密钥修改、补发、退款、紧急开关）全量写入审计日志。
- **分域凭证落库加密与滚动轮换**：数据库中的支付商户私钥、上游 API Secret、发信 API Key 与卡密凭证统一经 AES-256-GCM 加密存储并附带可切换版本 KeyID（`DATA_ENCRYPTION_KEYS`），查询检索借助 HMAC 指纹索引（`DATA_FINGERPRINT_KEY`），无需明文落库即可在线密钥轮换。
- **全站财务对账与自动化守恒巡检**：管理后台与 CLI 脚本（`operational-check.mjs`）提供实时对账与一致性质检，持续校验会员现金余额、消费金流水、代理佣金重复与差额、退款滞后、待交付滞留订单与邮件投递异常。
